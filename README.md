中文：

机器人使用说明

收藏帖子：

打开 Discord Forum 中需要收藏的帖子。
在该帖子的消息上打开“应用（Apps）”/“互动（Interactions）”菜单。
选择收藏机器人。
点击“收藏”功能。
收藏成功后，该帖子会加入你的收藏列表。

取消收藏：

打开已经收藏的帖子。
再次打开该帖子的“应用（Apps）”/“互动（Interactions）”菜单。
选择收藏机器人。
点击“取消收藏”即可。

命令：
/favorites — 查看自己的收藏列表。
/top — 查看历史累计收藏最多的帖子。
/top30 — 查看最近 30 天收藏最多的帖子。

收藏列表中的帖子会提供 Discord 帖子链接，点击即可直接进入原帖子。即使帖子标题发生修改，收藏仍然对应原来的帖子。

English:

Bot User Guide

Bookmark a Post:

Open the Discord Forum post you want to bookmark.
Open the “Apps” / “Interactions” menu on the post.
Select the bookmark bot.
Choose “Bookmark”.
The post will be added to your personal bookmark list.

Remove a Bookmark:

Open a post that you have already bookmarked.
Open the “Apps” / “Interactions” menu on the post again.
Select the bookmark bot.
Choose “Remove Bookmark”.

Commands:
/favorites — View your bookmarked posts.
/top — View the most bookmarked posts based on all-time statistics.
/top30 — View the most bookmarked posts from the last 30 days.

Bookmarked posts include a Discord post link. Clicking the link opens the original post directly. If the post title is changed later, the bookmark will still point to the original post.
